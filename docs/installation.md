# AssistantX Installation Guide

This guide explains how to install, configure, run, test, and build AssistantX on Windows.

AssistantX is designed primarily as a Windows desktop application and can be used in both development mode and packaged EXE mode.

---

## 1. System Requirements

### Minimum Requirements

- Windows 10 or later
- Python 3.11+
- 4 GB RAM
- At least 1 GB free disk space
- Working microphone for voice features
- Internet connection for online AI/web features

### Recommended

- Windows 11
- Python 3.11 or newer
- 8 GB+ RAM
- SSD storage
- Stable internet connection
- Functional microphone and speakers/headphones
