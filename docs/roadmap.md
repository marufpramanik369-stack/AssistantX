# AssistantX Roadmap

This document describes the planned development direction of AssistantX.

The roadmap is organized into phases so that the project can grow from a stable desktop assistant into a modular, extensible, and intelligent personal AI platform.

> Roadmap items represent development goals and may change based on technical requirements, stability, and project priorities.

---

# 1. Vision

AssistantX aims to become a professional Windows desktop AI assistant with:

- Chat-based interaction
- Voice interaction
- Long-term memory
- Conversation history
- Web assistance
- PC automation
- Task scheduling
- Multiple AI providers
- Modular architecture
- Plugin support
- Offline/local AI support
- Professional Windows application experience

The long-term goal is to make AssistantX a single extensible platform rather than a collection of unrelated features.
